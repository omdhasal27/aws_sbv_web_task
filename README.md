# AWS Student Builder Group - Web Development Prerequisite Tasks

Welcome to my repository containing the prerequisite web development tasks for the AWS Student Builder Group recruitment process.

---

## 🚀 Tasks Overview

### Task 1: Personal Portfolio Page
* **Description:** A responsive personal portfolio featuring an introduction, skills section, projects showcase, and contact form. Built with semantic HTML, CSS, and vanilla JS.
* **Key Features:** Light/dark mode toggle, CSS animations, and optimized for mobile/desktop.

### Task 2: Landing Page Clone
* **Description:** A pixel-grade clone of a modern landing page including a navigation bar, hero section, features, pricing cards, and footer.
* **Key Features:** Uses CSS Grid and Flexbox, plus a responsive mobile hamburger menu.

### Task 3: JavaScript To-Do Application
* **Description:** A functional task manager website where users can add, edit, delete, and mark items as complete.
* **Key Features:** Active/Completed filters, dynamic item counter, and data persistence using `localStorage`.
